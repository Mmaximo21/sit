# Secure File Hub

Gere um site para mim aonde eu consiga criar 10 usuarios com senhas diferentes e logins diferentes e que cada usuario tenha acesso somente ao um arquivo que irei enviar para seguir o padrão de acordo com a sua especialidade, apenas a especialidade Servico Social devera acessar o seu arquivo assim como as outras 2 enviadas, mas nesse site dever ter o usuario master que devera ter o acesso total aos arquivos com permissões de impor data para o preenchimento, fechar e editar arquivos que os outros usuarios enviarem...
